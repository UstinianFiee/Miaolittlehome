# 部署手册（最简命令版）

适用：**Ubuntu 24.04 / 4 核 4G / 1Mbps**、全新空 `/data`、Docker Compose v2。
已经部署过的站点升级请走 [更新手册](./更新.md)。

> 首次构建要拉 npm 依赖，1Mbps 下大约 5–15 分钟；构建期间网站不可访问，挑低峰做。

## 0. 装依赖（一次性）

```bash
sudo apt update && sudo apt install -y git curl
curl -fsSL https://get.docker.com | sudo sh     # 已装 Docker 可跳过
sudo systemctl enable --now docker
```

## 1. 拉代码

```bash
cd /opt
sudo git clone https://github.com/UstinianFiee/Miaolittlehome.git blog
sudo chown -R "$USER":"$USER" /opt/blog && cd /opt/blog
```

## 2. 数据目录 + 配置

```bash
sudo mkdir -p /data && sudo chown 1001:1001 /data
cp deploy/.env.production.example .env.production && chmod 600 .env.production
openssl rand -base64 48   # 输出填 JWT_SECRET
openssl rand -base64 24   # 输出填 IP_HASH_SALT
```

编辑 `.env.production`，至少改这几项：

| 配置 | 填什么 |
|---|---|
| `JWT_SECRET` / `IP_HASH_SALT` | 上面两条命令的输出（**生产环境会拒绝模板占位值**） |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 后台账号，密码用强密码 |
| `NEXT_PUBLIC_SITE_URL` | 访问地址：没域名先写 `http://服务器IP` |
| `RUN_SEED` | 首次部署设 `true`，初始化完成后改回 `false` |
| `DATA_DIR` | 默认 `/data` 即可；要换盘再改 |

## 3. 构建启动

```bash
docker compose --env-file .env.production up -d --build --wait
docker compose --env-file .env.production logs --tail=100 app
```

访问 `http://服务器IP/zh` 和 `/admin`，用后台账号登录。首次只有示例内容，属正常。

## 4. 关掉初始化开关

```bash
sed -i 's/^RUN_SEED=true/RUN_SEED=false/' .env.production
docker compose --env-file .env.production up -d --no-deps --wait app
docker compose --env-file .env.production restart nginx
```

## 5. 启用 HTTPS（有域名再做）

1. 证书放到 `deploy/nginx/certs/fullchain.pem`、`privkey.pem`
2. 改 `deploy/nginx/nginx.conf` 顶部 `map $host $site_canonical` 里的域名
3. `.env.production` 的 `NEXT_PUBLIC_SITE_URL` 改成 `https://域名`（构建期内联，必须重建）

```bash
docker compose --env-file .env.production up -d --build --wait
docker compose --env-file .env.production exec nginx nginx -t
```

云服务器安全组只放行 80/443；服务器防火墙同理。

## 6. 每月备份（放到数据目录之外）

```bash
docker compose --env-file .env.production stop app
sudo tar czf /root/blog-$(date +%F).tar.gz /data .env.production deploy/nginx/certs
docker compose --env-file .env.production start app
```

## 排障速查

```bash
docker compose --env-file .env.production ps                  # 容器状态/健康
docker compose --env-file .env.production logs -f app         # 应用日志
docker compose --env-file .env.production exec nginx nginx -t # Nginx 配置检查
sudo chown -R 1001:1001 /data                                 # 数据目录权限
```

- 502：app 没起来或健康检查失败，先看 app 日志
- 登录后跳不回后台：确认 `SESSION_COOKIE_SECURE` 留空、Nginx 透传 `X-Forwarded-Proto`
- 图片/视频 404：确认 `/data` 已挂载且属主是 `1001:1001`
